# Golden Test Dataset 设计与独立答案候选

关联 QA-001–004、VALID-001、BT-005。当前是设计与开发方独立手算候选，不是 Gemini 已核验的 Golden 基线；自动测试尚未实现。`tests/golden/` 只含说明。

每个 case 必须封存：case_id、需求ID、适用阶段、原始输入/单位/时区/市场假设、明确公式和中间量、独立答案、绝对/相对容差、答案来源及核对者/日期、输入与答案 SHA-256、schema/version、边界变体。reference 实现不得调用待测包或共用金融计算 helper；先核对答案再实现主功能。发现原答案错需缺陷/重新独立审查/版本变更，不覆盖旧记录迎合输出。

## 必须补齐的独立案例清单

P1：标识复用/跨市场、UTC/夏令时、交易日空洞、缺失/零量、冲突重复、历史股票池/退市、修订 available_at、拆股/红利 RAW/调整因子、哈希损坏。

P2：历史不足、全常数/分母0、非法参数、频率/major不兼容、同版本异代码、停用/回滚、跨证券窗口。P3：缺失成对过滤、极端值、全相等、并列、小n、分位数组不足、标准化/中性化秩亏、标签跨界 purge、Test 重用拒绝、HAC 和多重校正已知 p 值、所有候选保留。

P4：权重/净敞口/杠杆/换手边界、行业/Beta缺失、不可行约束、long-short 对称输入、借券不足。P5：空头买回及保证金/借券费/分红应付、零现金、价格tick/最小费/Decimal舍入、交收限制、同一时点多订单预留、部分成交、重复Fill、非法终态、延迟数据错过开盘、拆股/碎股、退市无mark、外部现金流收益、费用归因与账本独立重建。

独立参考 + 边界 + 性质三者同时约束关键金融数学/资金计算。性质不能证明具体数值答案：收益复合、相关系数界、秩不变、z均值0/样本方差1、权重敞口界、账本守恒、重复事件幂等、合法时序和无未来信息均需各自测试。

Gemini 核对输入/中间量/公式/容差并签署核验记录前，所有答案 `REVIEW REQUIRED`。P0 只要求设计充分；不把未来标准答案执行状态记 PASS。各阶段增加答案时保持版本与审批证据，关键金额答案必须支持人工复算。
