# 阶段验收与阻断制度

来源 V3.0 §§15–19、V3.1 §§1/8、V3.2 §§3–8；关联 GOV-001–009、QA-005–007、INT-001–006。

## 三类事实与状态

阶段状态：PLANNED、IN PROGRESS、TESTING、REVIEW REQUIRED、BLOCKED、ACCEPTED、RELEASED、NOT VERIFIED；ACCEPTED 只凭用户明确阶段验收记录，RELEASED 还需实际合并/标签。能力状态单列 Planned/Deferred/Unsupported/Implemented，不能与文档存在或阶段状态混同。

开发方报告结论 PASS / PASS WITH CONDITIONS / BLOCKED / NOT VERIFIED；Gemini 报告另允许 FAIL。PASS 仅对所审 SHA 与适用范围有效，不等于用户批准。CI 通过、Gemini 通过、用户批准分别记录。未运行、未见证据、模板字段为空均不得写 PASS。

## 强制门禁

G0：上一阶段人工验收、当前范围及启动授权明确（P0已由原指令授权）。

G1：Gemini 审查阶段计划/接口/测试标准，阻断设计问题闭环。未取得 Gemini 预审，允许准备提案，禁止将其作为已批准实施基线。

G2：范围内代码/文档完成，固定依赖/版本/数据；适用测试和回归实际通过，独立答案核对存在，需求追踪无关键遗漏。

G3：PR与完整 SHA、Review Package、原始 CI/本地日志；Gemini 审查指定 SHA，关键问题针对最终修复 SHA 复核。无 PR/无访问等缺项必须列 BLOCKED 或 NOT VERIFIED，不能用变动分支头替代。

G4：Critical/High 全关闭；Medium 按金融正确性/风险/安全/标准判定是否阻断并写理由；非阻断问题需负责人/处置与用户是否接受。争议保留双方原报告，以可复现测试或用户决策解决，GPT 不改 Gemini 报告。

G5：满足上述条件才可提交用户人工验收。批准记录含用户原意证据、Phase、完整 SHA、批准范围、条件、时间；“继续”“不错”不构成明确批准。

G6：按另行授权合并 main、创建实际标签并保存日志，更新 PROGRESS/CHANGELOG/TRACEABILITY；任何失败不报已发布。下一阶段需新的明确授权。

## 各阶段适用标准

| Phase | 正常验收需核对的证据 | 不得要求的未来依赖 |
|---|---|---|
| 0 | 编号需求/双向追踪、架构/接口/数据及事件契约、Golden设计、六专项审计、完整覆盖审计、待决项、Gemini设计审查 | 不要求业务测试/引擎/网页已运行 |
| 1 | 数据及时间/单位/快照、日历/PIT/清洗标准答案、固定环境及CI日志 | 不要求Registry/研究 |
| 2 | 注册/元数据/参数/版本/替换/回滚/API兼容、因子独立答案与时间边界 | 不要求研究、组合、回测 |
| 3 | 完整研究替换、五阶段处理、统计Golden及OOS隔离/多重实验证据 | 不要求资金账本/经济可交易性完整批准 |
| 4 | 单/多因子、多空权重与风险/不可行约束答案 | 不要求撮合、真实订单 |
| 5 | 时序自动测试、部分成交/成本/资金/行动/交收/估值独立对账、回测替换、绩效口径 | 不要求Streamlit |
| 6 | 六页面、任务日志/安全、CLI/服务/UI同配置因子选择与研究/回测数值一致 | 不把UI正常当金融核验 |
| 7 | 全研究/策略链、Momentum→Reversal E2E、双模式隔离、完整回归/泄漏审计、全新环境、手册、具体比赛规则证据 | 未知比赛规则单列外部阻断，通用模拟不能冒充比赛认证 |

## 阻断问题生命周期

OPEN→TRIAGED→FIXED_PENDING_RETEST→VERIFIED_CLOSED；拒绝/延期需依据与用户决策，不能自行删除。字段含 finding_id、审查者、Phase、发现 SHA、严重度/阻断理由、位置、复现步骤、预期/实际、后果、建议、负责人、修复 SHA、实际命令/日志、Gemini复核证据。新 SHA 可能重新打开问题；缺证据不自动关闭。

## 每阶段 A–F 报告

A 功能：Phase、需求ID、完成/未完成及原因、修改文件。

B 测试：实际命令、执行环境、通过/失败/跳过、原始日志、Golden核对/边界/性质/回归结果；无测试时写“未执行及原因”，不可写0失败等同通过。

C 技术：架构、接口、数学/金融、时间泄漏、安全、未解决缺陷；分清自查与 Gemini。

D 版本：分支、完整SHA、PR、数据/依赖哈希、实际可复现步骤；未建立项明确空缺。

E 结论：范围、适用标准、审查结论、人工批准状态分别列示。

F 下一步：是否具备人工验收申请条件、阻断项、下一阶段依赖/授权。停止，不自动继续。
