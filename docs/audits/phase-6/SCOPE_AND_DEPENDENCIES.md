# 阶段依赖、能力等级与拒绝边界

P1 已验收八表+manifest、PIT双时点与security/timezone契约 → 只能选可信工程catalog中的真实快照及侧车；不从任意网页路径构造输入。P2 精确Ref/元数据/注册治理 → 版本、参数与准入状态原样可见。P3完整研究/终态账本/验证报告 → 研究页及实验页。P4受限组合/风险 → 目标和风险视图。P5受限模拟事件/资金/绩效 → 回测页及真实状态。各项具体原需求依赖逐字保留于快照，不能在UI绕过。

六页面、任务、状态/失败/取消、配置版本/权重/回滚、报告和重放、CLI/UI同核及两因子完整链一致均是P6必需，必须真实实现后验证。Advanced Research（公式挖掘/机器学习等）保持Deferred；Production Extensions（真实账户/订单/部署/凭证管理）未授权且不进入本计划；P7完整替换E2E/比赛规则/最终部署另阶段，不把P6因子替换冒充P7全链验收。

研究数据限预先登记的合成开发/验证子集，公开页面不能选择私有正式Test。FINAL_TEST或formal strategy被篡改提交时必须在服务层明确拒绝，无工程回退、无订单、无私有数据读取。工程模拟仅使用已有TEST_ONLY批准制品与profile，界面显式说明不具有金融批准；不能把候选因子当正式已批准策略。

WI-R2-001（动态产物权限继承实际兼容）与WI-R2-002（operator实际输入发布/auditor读取证据）持续DEFERRED / NOT VERIFIED，整体真实Windows隔离亦同。R3代码修复、CI或GUI权限mock不得关闭两项。最终集成完整SHA上的真实三主体/输入/目录/动态产物/生命周期验证另行授权。原失败报告、日志、工件和哈希原字节保留。

正式Test未运行，金融批准NONE；完整历史宿主未验证，历史复现限已接受软件包/依赖锁/旧Ref/声明结果重放。旧run缺失制品或超出声明投影必须显示明确不可复现原因，不能声称任意历史宿主已还原。无账户启用、真实ACL/服务/调度、外网部署或实盘操作。
