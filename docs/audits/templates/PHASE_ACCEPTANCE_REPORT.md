# 阶段验收报告模板（A–F）

空白模板。A：Phase、需求ID、已完成/未完成、新增/修改文件。

B：实际命令/环境/时间/退出码、通过失败跳过、输出/日志hash、Golden核对、回归。

C：架构、接口、数学/金融、泄漏、安全、异常、缺陷与Gemini原审查链接及最终SHA。

D：开发分支、完整SHA、PR、数据/依赖版本与hash、可复现步骤；缺项不得编造。

E：开发方结论（PASS/PASS WITH CONDITIONS/BLOCKED/NOT VERIFIED）、Gemini结论（另允许FAIL）、用户批准（待定/原始批准证据）分别填写，注明范围和条件。

F：是否已具备人工验收条件、阻断项、下一阶段依赖及尚需决定事项。

用户正式验收字段：Phase、精确SHA、明确批准原文/记录、日期、条件、合并/发布是否另获授权、下一阶段是否另获授权。没有批准时保持待审，完成后停止。
