# Review Package 模板

开发方填写，独立审查结论另附，未知项明确 NOT VERIFIED。

1. Phase ID / 目标 / 计划或实现审查：待填
2. 仓库 / PR 链接或编号：待填
3. 完整待审 Commit SHA / 基线 / 修复后SHA：待填
4. 已完成需求ID和对应文件：待填
5. 未完成需求、后续阶段/外部依赖及原因：待填
6. 修改文件清单与diff：待填
7. 接口变更、兼容范围、迁移和影响：待填
8. OS/Python/锁文件/数据快照与哈希：待填
9. **实际**测试命令、工作目录、时间、退出码、通过/失败/跳过、原始日志：待填
10. CI run/attempt/job标识、结果、SHA：待填
11. Golden独立来源/核对者/容差/实际结果；性质与边界证据：待填
12. 已知问题/阻断项/严重度/缺陷索引：待填
13. 可复现步骤/所需权限/安全边界：待填
14. Gemini重点风险、计划预审记录及需独立核对点：待填
15. 已批准验收标准及来源/批准人；尚未批准处：待填

审查者应从指定SHA读取实际材料，不能只读本报告。运行不了写限制；修复提交新SHA重新验证。包完整性、独立审查、人工验收与版本发布分别记录。
