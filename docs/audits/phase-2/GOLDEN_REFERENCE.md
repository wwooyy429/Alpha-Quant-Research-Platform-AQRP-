# Phase2 独立数值答案（实现前封存）

本资料是手工定义的数学/时序与失败边界，不是待测函数生成的预期，也不是已经发布的P1八表快照。golden_cases.json 保留原始常量、计算依据、有理数、容差、invalid/exception语义和比较投影；实施时按P1 schema补全快照包装，不能用生成器输出反写正确答案。

| 案例 | Momentum | Reversal | Volume | 依据 |
|---|---|---|---|---|
| A：close100/110/121，volume100/150/200，L2 | 21/100=0.21 | -21/100=-0.21 | 3/5=0.6 | 121/100-1；200/125-1 |
| B：close200/180/160，volume40/60/50，L2 | -1/5=-0.2 | 1/5=0.2 | 0 | 160/200-1；50/50-1 |
| 2:1拆股，RAW价100→50、量10→20，L1 | 0 | 0 | 0 | PIT可见且已生效后，统一basis价50→50、量20→20 |
| 现金分红1，价100→99，量100→100，L1 | -1/100 | 1/100 | 0 | 三因子使用价格收益，不混用含分红总回报0 |
| 当期量0、历史100/150，价固定100，L2 | 0 | 0 | -1 | 当期0合法，不能与历史均量0混同 |
| A全部价量乘10 | 21/100 | -21/100 | 3/5 | 正比例缩放不变 |

异常/invalid案例包括历史均量0、少于L+1、可见日历中间缺bar、必要值缺失、非正价格、bool伪整数和目标available_at比decision晚1微秒。非法价格/参数是系统契约异常，不能当正常数值0；合法但资料不足输出null+reason。

Abs1e-12/Rel1e-10只用于最终float64因子值，有理数、Decimal、版本/hash/时点/状态精确核对。相同A输入只改Momentum Ref为Reversal Ref，数值+0.21→-0.21且direction均+1；回滚恢复+0.21，不改变旧run。

reference_arithmetic.py仅用标准库Fraction独立复核这些预先手写常量，无AQRP/Pandas/NumPy导入，不加载插件，也不能证明未来实现正确。其真实输出另存 reference_arithmetic.log；开发方参考执行不等于Gemini独立核对。本轮尚未运行任何P2因子函数。
