# G1 决策与发布门禁

1. P5-D01–D10为具体合成工程候选，须GPT Work预审；用户后续实施授权应明确接受该合成执行经济口径或要求修订。当前没有默认批准、不启动实现。特别审查：独立open侧车、T+1交收、每Fill最小佣金、oldshare红利/short应付、P4/E_alloc与Etotal投影、最差费用预算与全仓现金可用性、保守保证金及借券费。
2. 任一与P0/P3/P4契约冲突须作为显式设计变更提交，不能静默修改已验收文件。P4原账户缺应收应付支持已明确采用双投影保守适配候选，而非声称原接口已支持；若独立审查不能证明完整风险/资金一致性，该项阻断。
3. 正式市场/券商/税/融资/碎股、真实隔离、正式最终Test与金融阈值未定义或延期；不为完成工程验收虚构。工程实现范围内明确的long-short/行动/交收仍必须真实实现。
4. 当前技术/证据可用性待G1独立复核。数学候选检查仅开发方设计算术，P5业务SDK/双OS原ZIP尚不存在；既有P4证据不能填这些空位。G1 PASS也不等于实现、金融批准或验收。
5. G1修订需新完整SHA重审，PR中的锁定值随审查轮次更新但历史保留；不把漂移HEAD当固定版本。不合并计划PR或打新阶段标签，直到用户另行授权。
